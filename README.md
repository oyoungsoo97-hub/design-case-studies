## Scope and contribution

These studies accompany Youngsoo Oh’s UX and product design practice. The web prototypes were developed through design direction, iterative review and AI-assisted implementation and checks. The public repository contains newly written summaries and original explanatory diagrams. Source code, branded screenshots and detailed verification records remain in a private project repository. Diagrams illustrate the decisions; they are not screenshots or measurements.

Technical verification is not a substitute for user research. No adoption, conversion or performance improvement is claimed without evidence.
